#Grocery Store Checklist

**Author:** Ahmed Ibrahim

## Project Overview
This Python program helps people manage a grocery shopping list through a simple menu.

## Features
- Add grocery items
- View the grocery list
- Mark items as purchased
- Reomve grocery items
- View a shopping summary
- Prevent duplicate items

## How to Run
1. Install Python 3.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

    python3 grocery_checklist.py

## Python Concepts Used
- Variables and strings
- Lists
- Conditonal statements for loops and while loops
- User Input
- Functions
